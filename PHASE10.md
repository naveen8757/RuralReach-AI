# Phase 10 — Notifications & Communication

Added a lightweight communication center for RuralReach AI.

## Features
- Central notification center with student-specific filtering
- Professor announcements to all students or a class
- Important/urgent announcement priority
- Direct professor-to-student messages
- Broadcast messages
- Upcoming/live class alert view
- Notification creation from new announcements and direct messages
- Auto-refresh of communication data
- Responsive communication UI

## Run
`node server/server.js` then open `http://localhost:8080/communication.html`.

This remains a development prototype. Production use should add secure authentication, authorization, database persistence, HTTPS, rate limits and push notifications.

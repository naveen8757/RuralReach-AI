# Phase 21 — AI Project & Portfolio Builder

RuralReach AI now turns a student's learning direction into a practical project blueprint.

## Features
- Topic, career-track and difficulty inputs
- Offline rules-based project generator
- Problem statement, features, technology stack and milestones
- Portfolio-ready project summary
- Save projects locally
- Optional server persistence through `/api/projects`
- Copy blueprint to clipboard
- Export a standalone portfolio HTML page
- Random project ideas for demos
- Student dashboard shortcut

## Architecture note
This is an offline rules-based AI-style generator. It does not claim to be a cloud LLM. The architecture is intentionally lightweight for low-bandwidth rural environments.

# Phase 8 — Student Learning Dashboard

Added a student command center on top of Phase 7.

Features:
- Student profile/photo identity
- Enrolled/upcoming/live classes from central API
- Join live class directly from dashboard
- Central lecture list and quick open
- Offline download counts
- Attendance summary per enrolled class
- Lecture progress ring
- Learning notifications
- Offline-first dashboard toggle
- Responsive mobile layout

The offline mode intentionally uses locally saved data and does not claim live server access when disconnected.

# RuralReach Central Lecture Network — Phase 4

## Start
1. Open a terminal in the `RuralReach-AI` folder.
2. Run `node server/server.js`.
3. Open `http://localhost:8080`.

This is a development prototype of the central RuralReach server. It stores lecture metadata, uploaded media files, student records, and download events on the local machine.

## Important
This is not a production cloud server. For real Tamil Nadu-wide deployment, replace this local server with a hosted API/database/object-storage/CDN and add real authentication, HTTPS, access control, virus scanning, quotas, and resumable uploads.
